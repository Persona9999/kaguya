# 讀數全過還是去畫一張圖

**症狀**：所有讀數都在規格內、檢查全 ✓、主控台 0 錯 —— 而畫面是錯的。
不是讀數假（那是〈外觀 OK ≠ 真的 OK〉），是**讀數只回答「有沒有違規」，不回答「看起來對不對」**：
22% 的坡每一段都沒超挖深上限、作物每一株都種了、碼頭線每一段都在陸上 —— 只是陸是對岸那一塊。
報表只會說 blocked／✓，不會說「它被隔壁欺負了」「這是峽谷裡的運河」。

**可行動守則**：
1. 會被人**看到**的產出（地形、城、模型、路、港），讀數全過之後**再畫一張圖或進遊戲拍一張**，才算驗完。順序是先讀數、後圖 —— 圖不是取代讀數，是讀數的對照組。
2. 圖要拍**別人會看的那個角度與距離**（遠景／夜景／貼地），不是本小姐挑的那幾秒；能逐幕、逐座掃就掃。
3. 有懷疑的那一團，做**開關 A/B 各拍一張相減**（燈開關、城開關、舊成品對新成品），讓「是誰畫出來的」有讀數。
4. 圖上看到的錯，回頭問「為什麼檢查沒叫」—— 多半是工具跟檢查同源、或量的是錯的東西，把那把尺補上。

**為何 status 是 open**：一季踩了六次，每次都是事後才去拍。還沒變成「交件前一定先拍」的反射；有幾次（窗的白光、碼頭線）是差一點就拿修好前的圖去發噗。
